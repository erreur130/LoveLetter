# LoveLetter
Reconstitution graphique du jeu de carte Love Letter

Dans le projet git vous pouvez trouver :
- UML_x_x_xxx.jpg et .uxf qui correspond au diagramme de classe UML su projet en visuel et éditable via UMLet
- .github/workflows/build.yml qui permet de complier le projet avec github sur Windows, Linux et macOS
- .gitignore permet d'ignoré les fichiers sources / buils et autres fichiers de l'utilisateur
- FichierQT/ :
    - Images/ contient toutes les images des cartes en .png et du logo .icns et .ico
    - les autres fichiers sont les fichiers sources .h .cpp .ui .pro qui
